# مرجع المعمارية التخصصية

مرجع تنفيذي؛ نطاق الدعم العام وكتالوج الأدوات في الدليل الإنجليزي.

```
[Social Presence Operator]
      │
      ├─► [Assets]    SVG ← PNG ← فحص بصري ← check-social-assets (أبعاد + كشف الصورة الفارغة)
      ├─► [Pages]     LinkedIn Page · Facebook Page (وضع الصفحة) · X (حساب المالك فقط)
      ├─► [Posting]   بروتوكول الثريد: بوست ← لقطة ← إضافة ← نشر مرة واحدة ← عدّاد
      └─► [Handoff]   أسرار، أكواد، دفع، نوافذ منبثقة ← المالك بقيم دقيقة
```
