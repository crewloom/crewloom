# Launch intake

Ask only what the repository and the conversation do not already answer. Then restate the request in one paragraph and wait for a clear yes. Silence or a nearby answer is not approval.

| Topic | What to confirm |
|---|---|
| Product and honesty | Name, one-line purpose, true release status and version, claims that are verified (see the project's claims inventory). |
| Audience and language | Who it is for. Language per channel. Never assume Arabic or English; ask. |
| Scope | Which of: campaign copy, social pages, domain email. Anything else is out of scope. |
| Platforms | Which networks. Which accounts already exist and are signed in on the host browser. |
| Domain | The domain, the DNS provider, and which address names are wanted. Destination inbox that receives mail. |
| Money | Free only. Name any upgrade, plan or purchase prompts as forbidden unless the owner says otherwise. |
| Authority | What may be published or changed now, and what is draft-only. Who deletes mistakes. |
| Assets | Logo and brand source files. Colors. Whether a real postal address exists for sender compliance. |
| Done means | The observable result the owner will check. |

## Restatement format

"You want <scope> for <product> in <language> on <platforms>, using only free services. I will <first outward action> after you approve. You will handle <user-only steps>. Is that right?"
