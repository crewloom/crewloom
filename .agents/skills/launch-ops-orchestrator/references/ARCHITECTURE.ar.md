# مرجع المعمارية التخصصية

مرجع تنفيذي؛ نطاق الدعم العام وكتالوج الأدوات في الدليل الإنجليزي.

```
[Launch Ops Orchestrator]
      │
      ├─► [Intake]        أسئلة مؤكَّدة ← إعادة صياغة ← موافقة صريحة
      ├─► [Claims Gate]   check-launch-claims ← دليل أو إعادة وصف
      ├─► [Routing]
      │      ├─ نص وهوك  ← growth-director-orchestrator / viral-hook-architect / brand-identity-engineer
      │      ├─ صفحات    ← social-presence-operator
      │      └─ دومين    ← domain-email-operator
      ├─► [Approvals]     موافقة لكل إجراء + تسليم خطوات المستخدم
      └─► [Verification]  عدّادات، لقطات، ناتج أدوات ← تقرير صادق
```

**قيود ثابتة:** تكلفة صفر، لا إنشاء حسابات، لا إدخال أسرار، لا نشر قبل الموافقة.
