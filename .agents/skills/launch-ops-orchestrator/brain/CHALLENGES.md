# Challenges

Record the cause, attempted solution, result, and remaining blocker. Entries below are generalized from a real run; they hold no account identifiers or credentials.

### Publishing before the request was understood
- Cause: the first draft assumed Arabic content; the owner wanted English only for the main channel.
- Result: duplicate and unwanted posts had to be deleted by the owner.
- Rule: complete the intake, restate the request, and wait for a clear yes before publishing.

### Unverifiable marketing numbers in public copy
- Cause: site and draft copy carried latency, size, and "better than <product>" claims with no measurement.
- Rule: run `check-launch-claims` on every file and relabel or remove flagged claims.
